# 13 · Start membership and Developer Access (start today)

**Why this is the first job:** the Official Rules say *"internet access, Meta VR developer account, and Start membership are required to participate."* The person submitting must be a **Start Program member by submission time**, and the Meta account must have **Developer Access** enabled. Meta publishes **no approval time** for Start. If this is not approved, you cannot submit, however good the game is.

## 1. What Meta's pages say (read on 9 Nov 2026)

| Topic | What the sources say | Source |
|---|---|---|
| Required to enter | Developer account, Start membership, internet access. Membership and Developer Access needed **by the time you submit** | Official Rules, Competition FAQ |
| Solo entry | Allowed. One entry per entrant. You can enter solo **or** as a Team Representative, not both. A "Team" means at least two people, so you are an individual entrant | Rules, FAQ |
| Headset | **Not required.** Judges use a Quest 3 or 3S. Test with Meta XR Simulator, Meta Spatial Simulator or the **Immersive Web Emulator**. Video may show footage "as viewed on a Meta Quest device or via XR Simulator or another equivalent emulator" | FAQ, Rules |
| Eligibility | 18 or older and the age of majority where you live. Excluded: residents or organisations in **Brazil, Quebec**, and comprehensively sanctioned regions (Crimea, Russia, Cuba, Iran, North Korea, Syria). **India is not named as excluded.** Confirm in the full Official Rules yourself | Rules, FAQ |
| Start program terms | You need a valid email, the age of majority, and **a registered developer Organization in good standing**. If you do VR work within an Organization, it must be privately held. Meta decides membership and benefits at its sole discretion. Cost is not stated | Start Terms |
| How long approval takes | **Not published** | Start page, FAQ |
| How to check you are in | Log in to the Meta Developer Forum. You should see the flair **"Start Member"** or **"Start Partner"** next to your name | FAQ |
| Applied more than 24 h ago, no flair | If you meet the qualifications, **file a support ticket** at the Developer Support Center | FAQ |
| "Developer Access" | The FAQ uses the term but **does not define it or say how to enable it**. I could not find a definition on the public pages | FAQ |
| Pending membership at submission | Not addressed. The wording ("in good standing", "by the time you submit") suggests pending **may not count**. Treat it as a hard requirement | FAQ (my reading) |
| Known problem | A forum user reported the Start application page showing "This page isn't available" for weeks, with a support escalation still open on 26 Oct 2026. Another user said opening the program link redirects to the apply page (unverified) | Meta community forum |
| Prizes, if you win | One prize per entry. A bank account may be required for prizes of $1,000 or more. Meta may ask for a government ID. Non-US winners receive Form 1042-S. Winners are responsible for taxes. (I am not a tax advisor.) | Rules |

## 2. Do this in order (about 45 minutes of your time)

| Step | Action | Notes |
|---|---|---|
| **A** | Create your Meta developer account at `developers.meta.com/horizon/sign-up` using your Meta account | Complete the verification it asks for. Forum reports say **SMS to a mobile number** worked where an authenticator app did not. Avoid VoIP numbers if you can (my caution, not from Meta) |
| **B** | Open the **Developer Dashboard** (`developers.meta.com/horizon/manage`) and **create a developer Organization** | The Start terms require one. As a solo developer, register honestly in your own name. Do not claim a company you do not have. Meta says false statements can end membership |
| **C** | Apply to Start at `developers.meta.com/horizon/discover/programs/start/` (the Devpost page estimates 5 minutes) | Be accurate. Describe the project honestly: a solo developer building a seated, hands-first WebXR game with IWSDK for this competition. Link your repo and your hackathon portfolio if it asks for links |
| **D** | Register on Devpost: `start-developer-competition-26.devpost.com`, "Join hackathon" | Free, takes 2 minutes |
| **E** | Screenshot every confirmation and the dashboard showing your organization | Evidence for a support ticket |
| **F** | **In 24 hours:** log in to the Developer Forum and look for the "Start Member" flair | If absent and you applied more than 24 h ago, file a ticket at `developers.meta.com/vr/support/` |
| **G** | Ask in the **same ticket**: "What exactly is Developer Access for the Meta VR Start Developer Competition, and is it enabled on my account?" | The public pages never define it |

If the application page says "This page isn't available": try a private window, a different browser, and the program link above (it reportedly redirects). If it still fails, **file the ticket the same day** and post in the Developer Forum with the ticket number. Do not wait.

## 3. Deadlines for this track (your own, tighter than Meta's)

| By | What must be true | If not |
|---|---|---|
| **Mon 9 Nov (today)** | Steps A to D done, screenshots saved | Keep going, this is the critical path |
| **Tue 10 Nov** | Flair check done, ticket filed if needed | File it |
| **Wed 11 Nov** | Start membership approved | Post in the Developer Forum, reply to the ticket daily |
| **Fri 13 Nov** | Membership approved and Developer Access confirmed | Escalate again, state the 18 Nov deadline |
| **Tue 17 Nov** | **Go or no-go.** Approved: continue. Not approved: you cannot submit, so prepare the build and video anyway in case approval arrives before 12:00 PM PT on 18 Nov | There is no alternative entry path in the rules I read |

Keep building while you wait. Approval does not block the game, it only blocks the submission.

## 4. What to ask Meta Developer Support (copy this)

> Hello. I am entering the Meta VR Start Developer Competition 2026 as a solo entrant (Gaming track, New Experience, Immersive Web SDK). I applied to Meta Horizon Start on **[date and time, IST]** and created a developer organization named **[name]**. (1) What is the current status of my Start application, and when should I expect a decision? (2) What exactly is "Developer Access" for the competition, and is it enabled on my account **[Meta account email]**? (3) The deadline is 18 Nov 12:00 PM PT. Is there anything else I need to do to be eligible by then? Thank you.
