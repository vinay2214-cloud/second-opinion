# S2 · How do we know when a grabbed token is released, and where?
Verdict: PASS
Date / IWSDK version / device or emulator: Tue 10 Nov 2026 / @iwsdk/core 1.1.0-rc.2 / IWER emulator (metaQuest3), emulated hand tracking, pinch grab.

What I tried (in order):
1. Documented signal first. `node_modules/@iwsdk/core/dist/grab/grabbed.d.ts` documents `Grabbed`: a transient tag "Managed by GrabSystem", "Added when a grab handle captures one or more pointers", "Removed when all pointers are released and the grab ends". `elics/lib/query.d.ts` documents `subscribe(event: 'qualify' | 'disqualify', ...)`. This worked, so fallbacks (b) `Pressed` removal and (c) own drag were not needed and were not built.

What worked (code snippet or path): `src/spikes/s2-release.ts` (dev-only, loaded by a dynamic import in `src/index.ts`, absent from the production bundle).

```ts
export class S2ReleaseSystem extends createSystem({
  held: { required: [SpikeToken, Grabbed] },
  trays: { required: [SpikeTray] },
}) {
  init() {
    this.cleanupFuncs.push(
      this.queries.held.subscribe('qualify', () => { /* picked up */ }),
      this.queries.held.subscribe('disqualify', (entity) => {
        entity.object3D.getWorldPosition(this.tokenPos);   // where it was let go
        // compare with each tray's world position: |dx|,|dz| <= halfSize, 0 <= dy <= 12 cm
      }),
    );
  }
}
```
The token is `world.createTransformEntity(mesh).addComponent(OneHandGrabbable, { rotate: false })`. Hand pinch grabs by default (`GrabSystem.useHandPinchForGrab` defaults to true). Related documented helpers for T04: `world.getSystem(GrabSystem).forceRelease(entity)` and `.getHolderHand(entity)`.

3 of 3 correct, 0 console errors. Screenshot: `spikes/evidence/S2-cube-on-tray.png` (hands visible, cube above the tray).

Fallback chosen (if any): none. `docs/04` section 1 stands as written (pinch-grab, release over a tray). Tap-a-tray is not needed.

Impact on docs or tasks:
- T04 can use `[Token, Grabbed]` qualify/disqualify directly. `docs/03` section 2 "not documented" item 1 is resolved.
- The token stays exactly where the hand lets go (no gravity, physics is off). It hung about 7 cm above the tray. T04 must do the snap itself.
- `disqualify` also fires if the entity is disposed or loses `SpikeToken` while held. T04 should treat release as "Grabbed removed while the token is still alive".
- Not tested: tracking loss mid-grab on a real headset (does `Grabbed` drop when the hand leaves view?). The emulator cannot show this. Worth one check by the remote Quest tester.
- The emulated reach lands within about 2 cm of the requested point, so tray hit areas should keep a margin (the 11 cm tray with 4 cm gaps in `docs/04` is fine).
