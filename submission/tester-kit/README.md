# Second Opinion: tester script

Thank you for testing. This takes about 20 minutes. You need a **Meta Quest 3 or 3S**, a table, and a chair. No controllers: the game uses your hands.

**Link:** https://vinay2214-cloud.github.io/second-opinion/

Please do not read about the game first. The point is to see what a new player does.

## Before you start
1. Sit at a table with about 60 cm of clear space in front of you. Move drinks away.
2. Put the controllers down so the headset switches to hand tracking.
3. Start a recording of your view: press the Meta button, open **Camera**, choose **Record video**. (You can also say what you are thinking; the microphone option is in the same place.)

## Run 1: normal
1. Open the link in the **Quest Browser** (the built-in browser).
2. Tap **Enter XR** and allow the permissions it asks for.
3. A glowing pad appears on your table. Pinch it to place the game. If no pad appears within a few seconds, the game places a virtual table for you.
4. Play **Module 1** to the end (about 3 minutes). It has a short tutorial.
5. Then play **Module 3** once (about 7 minutes).
6. **Think aloud** the whole time: say what you expect, what you are trying to do, and what confuses you. Do not look anything up. If you are stuck for a minute, say so and move on.

## Run 2: with the debug panel (2 minutes)
1. Open this link instead: https://vinay2214-cloud.github.io/second-opinion/?debug=1
2. Enter XR and place the game again. A small purple panel appears to the **left** of the big text panel. It shows the build tag, frames per second, hand tracking state and the last error.
3. Start Module 3 and wait until two patients are on the table at once (about two and a half minutes in).
4. Take a screenshot with the purple panel in view: Meta button, **Camera**, **Take photo**.

## If it stutters or things look wrong
Open https://vinay2214-cloud.github.io/second-opinion/?debug=1&safe=1 and try again. This turns off see-through effects. Tell us whether it helped.

## Then
1. Stop the recording.
2. Fill in `feedback-form.md` (copy it into a message or a document).
3. Send back: the recording, the debug screenshot, and the form.

`known-issues.md` lists things we already know about, so you do not need to report those.
