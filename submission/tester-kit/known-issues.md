# Known issues (no need to report these)

- **There is no sound.** Every event is shown visually.
- **A shift ends at the review screen.** Poke Map for the trust map, or a module button to play again. There is no further ending.
- **The same patients appear every time** you play the same module. That is intentional for testing.
- **Calm mode** (in the Menu) takes effect from the next shift, not the current one.
- **Big text** enlarges the two upright panels only, not the card on the table.
- **A token on a tray is small** (about 3.5 cm) and sits in the tray's back corner so the tray's shape stays visible.
- **In a flat browser** (phone or computer) the page only shows the table and a line telling you to open it on the headset. It is playable only in the headset.
- On a small or round table the front corners of the game board may hang over the edge. On a normal desk they should not. Please tell us if they do.
- The game was built and tested only in a software emulator. You are the first to run it on a real headset, so rough edges with real hands are expected and are exactly what we want to hear about.
